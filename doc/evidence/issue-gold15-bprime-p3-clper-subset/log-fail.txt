# issue-gold15-bprime-p3-clper-subset —— 失败面与守卫现场（2026-10-13）

## 1. 扩充前阻塞现场（修改前未支持指令）

修改前遇到真机字 0x00a0c3101c0fc402：
错误：不支持的指令 CLPER.i32（P2 子集外）
exit 2

遇到真机字 0x68a0c510180fc802（flow=discard）：
错误：IADD_IMM.i32 / CLPER.i32 带未建模的 flow 修饰 discard（0x68a0c510180fc802）
exit 2

## 2. 负向对照渲染现场（clper_neg 错期望）

以错误期望 (0, 0, 0, 0) 运行 harness 对照正例渲染输出（正确色值为 51, 102, 153, 255）：
$ ./harness clper.frag.spv clper.vert.spv 0 0 0 0
像素(66,65) 在三角形内但为 51,102,153,255
像素(67,65) 在三角形内但为 51,102,153,255
像素(68,65) 在三角形内但为 51,102,153,255
像素(69,65) 在三角形内但为 51,102,153,255
像素(70,65) 在三角形内但为 51,102,153,255
逐像素比对：256x256，三角形内 7812 px、外 0 px（边界带跳过），失败 7812
exit 1

证实：像素并非假阳性全 0，且 harness 能精确逐像素比对并拦截错误值。

## 3. fail-loud 守卫现场 1：fl_clper_op（未建模的 lane_operation）

指令：CLPER.i32.subgroup4.xor.zero r3, r2, 0x0（lane_operation=1 为 xor）
$ python3 va2spirv.py fl_clper_op.bin fl_clper_op.frag.spv fl_clper_op.vert.spv
[00] 0x0091c200000000c0  MOV.i32            dest=reg:2 srcs=[lut:0] flow=none
[01] 0x00a0c311000fc002  CLPER.i32          dest=reg:3 srcs=[reg:2, lut:0] flow=none
      meta={'subgroup_size': 1, 'lane_operation': 1, 'inactive_result': 0}
[02] 0x7800c00000000000  NOP                dest=None srcs=[] flow=end
错误：CLPER.i32 翻译失败：CLPER.i32 暂不支持 lane_operation=1
exit 2
