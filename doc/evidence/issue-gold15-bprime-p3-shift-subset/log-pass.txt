## 1) 编码回环：真机字 ↔ asm.py（3/3 逐位命中）

    LSHIFT_OR.i32 r8, r6, 0x0.b00, r7       -> 0x00b4c8011107c006   (bin-007f00006c80[05])
    LSHIFT_OR.i32 r8, r4, 0x0.b00, r5       -> 0x00b4c8011105c004   (bin-007f00006c80[07])
    RSHIFT_AND.i32 r0, r61, 0x13121110.b00, u6.w1 -> 0x00b4c000108dcc3d   (bin-007f00026e00[03])

（三条均与 P3 采样字逐位一致。`0x13121110` = Immediates LUT index 12；`u6.w1` = FAU u6 高字，编码 0x8d。）

## 2b) 真机取材（frag_shift_real，112B / frag 776B；2 条真机 LSHIFT_OR 字）

    [05] 0x00b4c8011105c004  LSHIFT_OR.i32      dest=reg:8  srcs=[reg:4, lut:0, reg:5] flow=0
    [08] 0x00b4c8011107c006  LSHIFT_OR.i32      dest=reg:8  srcs=[reg:6, lut:0, reg:7] flow=0

（真机 shift 源为小常量 LUT 0x0 = 0，`.b00` 字节选择 → 移位量 0，即纯按位或。）

## 3) spirv-dis 核对（frag，移位族行）

    --- shift ---
         %24 = OpShiftLeftLogical  %int %16 %18       <-- LSHIFT_OR r4 = r10 << r11
         %25 = OpBitwiseOr         %int %24 %19       <--   ... | r12
         %26 = OpShiftRightLogical %int %21 %22       <-- RSHIFT_AND r5 = r14 >> r15
         %27 = OpBitwiseAnd        %int %26 %23       <--   ... & r16
         %30 = OpBitwiseAnd %int %25 %int_65535       <-- U16_TO_F32 低 16 位掩码
         %31 = OpConvertUToF %float %30
         %34 = OpExtInst %float %13 Fma %31 %float_0_100000001 %float_0
    --- shift_real ---
         %21 = OpShiftLeftLogical %int %16 %int_0     <-- LSHIFT_OR r8 = r4 << 0
         %22 = OpBitwiseOr        %int %21 %17
         %30 = OpShiftLeftLogical %int %18 %int_0     <-- LSHIFT_OR r8 = r6 << 0
         %31 = OpBitwiseOr        %int %30 %20

    $ ./harness out_shift_real.frag.spv out_shift_real.vert.spv 0 51 153 0
    逐像素比对：256x256，三角形内 7812 px、外 0 px（边界带跳过），失败 0   exit=0

    $ ./harness out_shift_neg.frag.spv  out_shift_neg.vert.spv  0 255 0 0
    逐像素比对：256x256，三角形内 7812 px、外 0 px（边界带跳过），失败 0   exit=0

（`shift`：r0=(2<<1)|2=6→6*0.1=0.6→153；r1=(12>>2)&2=2→0.2→51。
 `shift_real`：r1=2|2=2→51；r2=2|4=6→153。
 `shift_neg`：r0=(2>>1)&2=0→0；r1=(12<<2)|2=50→clamp 1→255。）

## 8) fail-loud（两条守卫，均 exit 2）

    $ python3 va2spirv.py fl_shift_notres.bin ...   # LSHIFT_OR.i32 置 not_result（bit30）
    错误：LSHIFT_OR.i32 带未建模的 not_result 修饰（0x00b4c401510c0b0a）
    exit=2

    $ python3 va2spirv.py fl_shift_widen.bin ...    # shift 源字节选择改 0（非 .b00，widen!=4）
    错误：LSHIFT_OR.i32 shift 源字节选择未建模（widen=0x0，仅支持 .b00）
    exit=2

（另：B 源 `not`(bit35)、A 源 `widen`(bit36-39) 由 src_mod_mask() 自动纳入，
 出现即报「带未建模的源修饰」exit 2，本批一并覆盖。）
