# issue-gold15-bprime-p3-shader-recapture —— 失败面（2026-10-13）

[1] 首轮内核构建被会话中断杀死（后台 job 丢失，日志停在 mali_kbase 编译中）
  → 重启 CDH_REFRESH_KERNEL=1 全量重建成功。教训：构建长任务须防会话中断，
    重跑成本可接受（约 4 分钟，docker 层缓存在）。

[2] adb shell dmesg 抓取扑空：P3 输出被 dmesg ring 滚掉
  4KB dump 使 P3 输出 ~8000+ 行，实例 98 抓取时 dmesg ring 已覆盖 t<133s，
  P3 块（t≈25-40s）被挤出——grep P3 标记 0 命中（49030 行 dmesg 里全无）。
  → 改从实例 runtime 目录的 qemu.log 提取（daemon 从 UEFI t=0 全量聚合 serial
    console 流，P3 输出完整落盘）。教训：大 dump 场景 dmesg 不可靠，
    console 聚合流才是全量取证面。

[3] Android Console（端口 5910）不可用作日志流：连接即要求 auth <token>。

[4] zsh 不对含空格变量分词：ADB="adb -s 127.0.0.1:5911" 后 $ADB shell …
  报 "command not found: adb -s 127.0.0.1:5911"（bash 无此问题）。
  → 循环内一律写显式 adb -s 命令。

[5] 提取器首版在 console 流上块被截断（dump=32B/64B 异常小）：
  qemu.log 的 hexdump 行与其它线程日志行交错，旧"遇非 hexdump 行即终止块"
  逻辑把块切碎。→ 改为「任何 P3 标记行才终止/开块 + hexdump 按 offset 落位」，
  同址同偏移取首、偏移缺口告警。旧 p3-dmesg3.txt 回归 10/10 md5 对齐后上线。
  另修：cur="ignore" 字符串被 finalize(*cur) 解包成 6 个字符参数（TypeError）。

[6] E2E 扩展过程中的 fail-loud 面（逐个暴露、逐个收敛到 6/10）：
  a) LSHIFT_AND.i32 / LSHIFT_XOR.i32 / CSEL.u32 / LSHIFT_*.v4i8 / ICMP_OR.v4u8 /
     U8_TO_U32：v4i8 打包整数族 P2 子集外（01000，未做，遗留）；
  b) BRANCHZ 区内嵌套分支（06c80/34180/37380）：translate 仅支持非嵌套
     if-then，完整 shader 露出嵌套 CFG（未做，遗留）；
  c) FMAX.f32 带 clamp 修饰（26e00）：旧 fail-loud 拦截 → 改为按 ISA Clamp
     枚举建模（1=clamp_0_inf / 2=clamp_m1_1 / 3=clamp_0_1，FMin/FMax 等价式）；
  d) FCMP_OR.f32 C 源为谓词寄存器（34180/37380）：旧"仅建模常量"不够，
     真机用比较族谓词链式累积；
  e) spirv-val: "Expected unsigned int scalar or vector type as Result Type:
     UConvert"（37880）：_pack_f16_pair 里 u16→i32 直接 OpUConvert 违规
     （结果类型须无符号）→ u32 域移位/或后 OpBitcast 回 i32；
  f) run_matrix fl_cmp_csrc 负例回归（69/1）：放开 C 谓词寄存器后"非常量 C"
     不再 fail-loud → 引入 pred_regs 判据（仅比较族写过的寄存器可作 C 源），
     fl_cmp_csrc 的普通寄存器 C 仍 fail-loud，70/70 恢复。
