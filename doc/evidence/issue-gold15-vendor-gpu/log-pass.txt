对照：本 CDH 内核 `out/kernel/kernelrelease.txt = 6.6.127-4k-cdh`（vermagic 亦为 6.6.127-4k-cdh）

并且 kbase/ged 均带 `of:` alias（`arm,mali-valhall` / `mediatek,ged`）→ **靠 DT 节点 probe**，QEMU virt 无此节点。

→ **寄存器级 Job Manager 驱动（real_hw）**，下游是 Mali GPU 硬件本身 → 与 virtio-gpu 的 virgl/venus 无语义映射，
"桥接"等价于实现 Mali-G57 软件模拟器。（详见 ../gpu.md §6）
