1. Virtgpu Double Free Fix
----------------------------------------
Kernel File: drivers/gpu/drm/virtio/virtgpu_prime.c:223
Commit: 01ad98489a4d ("drm/virtio: fix double-free of sg_table ents in virtgpu_prime")
Root Cause: virtio_gpu_object_attach() stores ents in vbuf->data_buf and frees it asynchronously via free_vbuf().
Synchronously calling kvfree(ents) causes SLUB freelist corruption and kernel panic at ~41s / 184s.
Fix: Removed redundant kvfree(ents); Kernel recipe updated to v90-doublefree.
Result: System stability verified, running continuously past 216s+ without SLUB crash.
