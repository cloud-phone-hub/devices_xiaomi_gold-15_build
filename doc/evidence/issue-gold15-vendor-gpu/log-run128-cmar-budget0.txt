## 死锁机制（逆向闭合）
read 门控 0x1cf23f4-0x1cf2404：len = min(budget, 8) = min(0,8) = 0
  → 0x1de4b10 __read_chk(fd, buf, 0) 恒读 0 字节
  → 内核 event_list 146 个 atom 事件永滞留（atoms 表头 ec=146 wc=0 cj=0，全 St=4 从未消费）
  → kbase_poll kbase_event_pending(event_count=146≠0) 恒返回 EPOLLIN
  → poll(sp+0x10, 4fds, timeout=-1[0x32ff2d0]) 立返 POLLIN
  → cbz budget=0 跳过 read → 回 poll → 死自旋（syscall=running，4s utime+86/stime+97 ticks）

## 结论
节点池（0x6d0 计数 + 0x6e8 分配计数 + 0x6d8 free-list + 0x6ec sem）从未播种/已耗尽，
read 门控被 0 卡死。非内核事件语义问题、非丢唤醒、非超时自旋（poll timeout=-1 已排除）。
